# CLEDAN FC - Official Football Club Website

A modern, fully-featured football club website built with PHP, MySQL, CSS, and JavaScript.

## Features

- ✅ **Dynamic Squad Management** - Add, edit, and manage players
- ✅ **Staff Management** - Manage coaching and support staff
- ✅ **Match Center** - Live scores, fixtures, and results
- ✅ **News & Blog** - Club announcements and match reports
- ✅ **Ticket Booking** - Online ticket purchasing system
- ✅ **Contact Form** - Fan communication portal
- ✅ **Admin Dashboard** - Full content management system
- ✅ **Responsive Design** - Works on all devices
- ✅ **Search Functionality** - Search players and news
- ✅ **Player Profiles** - Detailed player statistics

## Tech Stack

- **Backend:** PHP (OOP)
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Styling:** Custom CSS with modern design
- **Security:** Prepared statements, password hashing, CSRF protection

## Installation

1. Clone the repository
2. Import `database/cledan_fc.sql` to your MySQL database
3. Update `includes/config.php` with your database credentials
4. Set up your web server (Apache/Nginx) to point to the project root
5. Default admin login: `admin` / `admin123`
